# Rorilo v0.2.0

This release improves job discovery, application preparation, Gmail integration, and desktop reliability.

## Job discovery

- Describe a search in natural language and turn it into roles, keywords, location, country, and date filters.
- Add a job manually or paste a job posting to extract its details into the add-job form.
- Search StepStone and Xing through the free-source integrations.
- Select multiple jobs for bulk actions, with clearer search statistics and sorting controls.
- Google Jobs now preserves company names, application links, and job IDs. Small searches request the actor's minimum result count, and unsupported countries produce a clear error.
- Improve handling of empty results, source timeouts, retries, and job-description parsing.

## Application preparation

- Refine the job drawer, sidebar, Discover page, application tracker, and mobile layouts.
- Edit job descriptions and contact email addresses, and remove jobs directly from tracker cards or the drafts list.
- Improve CV parsing, setup guidance, skill matching, and application-language detection.
- Make requested revisions to application materials more reliable.
- Improve PDF export and remove invisible characters from generated documents.

## Integrations and desktop fixes

- Add Google OAuth sign-in for Gmail, improve token refresh handling, and refine email drafting.
- Improve compatibility with OpenAI-compatible providers.
- Support optional Basic Auth for hosted deployments; desktop sessions continue to run locally without it.
- Fix Windows desktop sidecar startup, Linux AppImage resource lookup, and Linux rendering defaults.
- Exclude local databases and environment files from desktop server bundles.
- Avoid duplicate-column migration errors, invalid-currency crashes, and locale-date hydration errors.

## Packages and upgrade notes

- Desktop targets: Windows installers, macOS Intel and Apple Silicon disk images, and Linux AppImage.
- Back up your local database before upgrading, and retain its existing location.
- Free sources, Apify actors, your model provider, and Gmail retain their own configuration requirements. Apify searches can incur charges.
- Google Jobs is optional and remains unchecked until selected. In this release it supports Germany, Austria, Switzerland, the Netherlands, Spain, Italy, the United States, Canada, and the United Kingdom.
