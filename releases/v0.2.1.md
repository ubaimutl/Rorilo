# Rorilo v0.2.1

## Linux AppImage database fix

- Bundle Prisma query engines for both OpenSSL 1.1 and OpenSSL 3, alongside the native build target. This fixes the missing `debian-openssl-1.1.x` engine error when opening the database in the Linux AppImage.
- Add a database smoke test that uses the bundled Node runtime and Prisma client to write and read a temporary SQLite database.
- Run that test on every desktop platform, in Linux environments with OpenSSL 1.1 and OpenSSL 3, and against the extracted Linux AppImage before uploading installers.

Replace the v0.2.0 AppImage with this version. No database reset or schema change is required; retain your existing data directory.

Full changes: https://github.com/ubaimutl/Rorilo/compare/v0.2.0...v0.2.1
